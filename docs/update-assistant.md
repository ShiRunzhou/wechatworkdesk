# WCWD 更新助手

双击项目根目录的 `启动WCWD更新助手.cmd`，本机界面为 http://127.0.0.1:8771 。助手与网站共享代码仓库，独立运行；不在本地另建事项数据库，不修改WeFlow配置。

1. 展开本设备与网站设置，核对WeFlow配置路径、本机导出目录、网站地址及账号；填写网站密码。密码只留在运行内存中，重启须重新填写。
2. 读取联系人和群列表，检查网站连接，勾选需要更新的会话。首次使用须在每行指定网站原有对象；未选择时将新建带微信标识的对象，不按相似姓名自动合并。
3. 默认从点击更新时回溯7天；自定义日期精确到天，包含开始和结束当天。可保存常用选择范围；默认范围使用上一次成功更新的选择。
4. 选择仅导出、上传后打开工作台、准备Agent任务或调用网站模型分析。API分析使用网站当前保存的模型接口，助手不保存分析模型密钥。
5. 查看日志。上传失败后重试复用本次固定资料，不重新导出；失败会话不阻塞其他会话。成功上传的会话不重复上传。

关闭浏览器页面不会结束助手，可点击页面“关闭更新助手”；更新进行中不允许关闭。再次双击启动文件可重新打开。联系人列表和网站对象对应关系缓存在本机，必要时点击刷新；首次实际开始前核对选择和对应关系。

消息按WeFlow账号及消息标识去重，不覆盖旧导出。网站收到本轮时间窗口的完整Markdown资料及附件（包含本地跳过的消息），按内容哈希去重；上传去重不等于模型分析去重。保留完整本轮资料，避免最新上传仅含差量造成上下文缺失。新一轮变化的资料可能产生新快照，历史事项标识由后续分析沿用。

语音优先复用WeFlow已有缓存与旧导出转写；配置兼容的 `/audio/transcriptions` 接口后，可以读取WeFlow音频媒体并在内存中转写。支持HTTPS远程接口或HTTP本地接口，成功转写缓存按WeFlow账号隔离。密钥仅保存在运行内存中。转写失败保留明确缺口，不推测内容。助手不把音频写入自己的导出目录、压缩包或网站；WeFlow自身可能会生成媒体缓存。

当前WeFlow HTTP接口没有文件附件导出路由。助手可以带上旧导出已经存在的文件；新文件缺失会明确标记。需要先用WeFlow手动导出相应文件，再重新更新这一时间范围。图片通过现有媒体接口读取。

本机设置、任务日志、打包结果和转写缓存位于 `data/assistant`，不纳入Git。不同电脑各自配置路径，上传到同一网站。助手只绑定127.0.0.1，并校验请求Host、Origin。对可能已经发出的上传和模型请求不自动重复；连接失败由用户重试，避免重复分析消费。

第一版不包含自动后台定时更新、可执行安装包或双向同步原始微信数据库。构建验证使用模拟资料；真实导出、上传和语音接口需在用户第一次实际更新时核验。
