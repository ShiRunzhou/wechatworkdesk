# 分析用量优化与验证（2026-10-15）

## 修改

- 网站按消息身份及正文、关联附件版本复用已发布分析。重叠范围跳过不变消息，新增、补转写及附件变化仍分析；人工反馈、已生效规则、工作背景和分析需求改变后重新核查。
- 背景文件不作为新聊天通知处理，旧任务的错误背景分类也在继续执行时跳过。背景读取按文件路径及内容去重，限制单次补充背景长度；既有事项上下文移除数据库元数据和重复证据。
- 补查限当前对象，先排除已提供的行段及同一消息的原始/派生副本，默认一次补查。不再每段自动扫描多组固定关键词。
- DeepSeek节省模式：普通提取、附件提取和补查关闭思考；最终核对沿用用户思考配置。每次输出最多8192 tokens。
- 默认整轮上限60次请求、300000 tokens。到限暂停并保存有效检查点；提高上限可继续，已完成结果不会重跑。失败、截断和格式不合格响应的已知用量计入统计。
- API与Agent提交均会更新同一复用记录；Agent未完整阅读的消息不记为已分析。没有新增资料时直接结束，不需再次交给Agent。
